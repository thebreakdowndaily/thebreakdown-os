# Instagram skills for The Breakdown

These project-local skills describe reusable research and editorial workflows for Instagram. Each capability lives in its own folder with a SKILL.md and can be independently revised.

## Recommended chain

instagram-source-research → instagram-brand-voice → instagram-carousel or instagram-reels → instagram-caption → instagram-quality-auditor → human approval.

Use instagram-content-calendar and instagram-repurpose for planning. Use instagram-profile-audit and instagram-performance-audit when the user supplies profile snapshots, post examples, or native Insights data.

## Operating rules

- Read the canonical project instructions and existing Instagram command/formatter first.
- Do not silently resolve conflicts in brand colors, typography, slide dimensions, or density.
- Keep material claims connected to traceable source records.
- Do not log into Instagram, scrape at scale, publish, schedule, like, follow, comment, message, or alter account settings.
- A successful audit means ready for human approval, never approved to publish.
