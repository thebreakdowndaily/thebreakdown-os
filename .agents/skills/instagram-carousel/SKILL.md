# Instagram Carousel

## Required inputs
Approved source brief; intended reader; single learning promise; content goal; desired slide count; approved assets; current brand and template specification.

## Workflow
1. State the single promise the carousel will fulfil. Stop if the evidence cannot support a clear payoff.
2. Draft a specific cover that states the subject and payoff without clickbait.
3. Build only the narrative beats needed: stakes, evidence, mechanism/context, implications, recap, and next step.
4. Keep one main idea per slide. Make headlines scannable; avoid dense paragraphs, tiny text, unexplained acronyms, and unlabelled figures.
5. Map each factual slide to source IDs in the claim ledger. Label estimates, time periods, denominators, and units.
6. For charts, specify data source, measure, unit, period, denominator, axes, caveats, and an accessible text summary. Never distort scales or imply causation from correlation.
7. Label each visual as existing approved asset, chart to build from sourced data, illustration, or asset needed. Never claim an asset exists if it does not.
8. Follow current project templates. Existing Instagram instructions differ on colors, aspect ratio, and slide density; flag the conflict rather than guessing or changing brand files.
9. Supply alt text for each slide and hand off the caption to instagram-caption.

## Output
Goal; audience; promise; slide count; narrative arc; slide table with role, exact copy, visual direction, source IDs, and alt text; design/export notes; missing assets; caption handoff; status DRAFT.

## Quality gate
The story should be understandable from slide headlines alone. Every material claim maps to evidence. No fabricated charts, quotes, assets, or visual provenance. Never publish.
