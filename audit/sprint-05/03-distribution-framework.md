## 1. Distribution Philosophy

The Breakdown never creates clickbait social snippets or duplicate SEO articles to feed social algorithms. Every distribution asset is a direct projection of canonical research that leads back to the primary knowledge object:

```
[Canonical Research Object (Story / Tracker / Document)]
                          │
       ┌──────────────────┼──────────────────┐
       ▼                  ▼                  ▼
[The Breakdown Brief] [Social Analysis]  [Direct Messaging]
   (Weekly Email)     (X / LinkedIn)    (WhatsApp / Telegram)
       │                  │                  │
       └──────────────────┼──────────────────┘
                          ▼
            [Standardized UTM Parameter]
                          ▼
            [Canonical Reading Surface]
```

## 2. Platform Distribution Archetypes

### A. The Breakdown Brief (Owned Newsletter)
- **Format**: 600–800 words, single-topic focus, 3 key numbers, 1 primary document highlight, link to live tracker.
- **Tone**: Matter-of-fact, evidence-first, zero speculative adjectives ("clearly", "obviously").

### B. Analytical Social Thread (X / Twitter)
- **Post 1**: Core assertion + verified date + visual chart.
- **Posts 2–4**: 3 key data points with cited source institutions (e.g. NPCI, MoRD, RBI).
- **Post 5**: Primary document quote (§ citation).
- **Post 6**: Canonical URL with `utm_source=twitter&utm_medium=social_thread`.

### C. Institutional Summary (LinkedIn)
- **Format**: 300-word executive briefing with key policy implications, chart graphic, and direct link to live policy tracker with `utm_source=linkedin&utm_medium=organic_post`.

### D. Direct Messaging Broadcast (WhatsApp / Telegram)
- **Format**: Bulleted 4-line summary: What changed, New rule / limit, Who it affects, Direct link to verify.
