# SEARCH INTENT TAXONOMY FRAMEWORK

We classify search traffic into structural templates to ensure that search intent aligns with evidence-first formatting.

| Search Intent | User Question | Landing Template | Evidence Component | Key KPI |
| :--- | :--- | :--- | :--- | :--- |

| **Explanatory** | "How does UPI offline payment work?" | Deep Research | Interactive System Diagram | Reading depth |
