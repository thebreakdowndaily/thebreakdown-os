# EVERGREEN CONTENT REFRESH RULES

To maintain search rankings and authority, content must not be left stale. We enforce the following trigger system.

## 1. Systematic Update Triggers

| Trigger Event | Verification Threshold | Required Action | Freshness Signal |
| :--- | :--- | :--- | :--- |
| **New Annual Budget** | Official Finance Ministry releases | Update fiscal statistics in 72 hours | Last Verified date updated |
| **Statutory Repeal/Amendment**| Gazette Notification S.O. | Prepend transition banner, link new Act | Redirect old URL if appropriate |
| **CAG Audit Publication** | CAG portal PDF drop | Insert audit findings & evidence badges | Recalculate Evidence Score |
| **Ranking Position Drop (>3)** | GSC Weekly Monitor | Audit SERP for new user intents / format changes | Expand article depth |
| **Outdated Statistic (>1 yr)** | Periodic check | Audit facts and charts variables | Verification timestamp bump |

## 2. Change Log Requirements
Every content refresh must append to the article metadata a public-facing change log containing:
1. Date of revision.
2. What changed (specific paragraphs, metrics, or charts updated).
3. Why the revision occurred (reference the primary source document that triggered the update).
