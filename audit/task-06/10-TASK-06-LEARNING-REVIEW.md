# TASK-06 LEARNING REVIEW

We analyzed performance metrics of the first batch (CNT-HP-01 to CNT-HP-07).

## 1. Format Performance
- **Timelines** (e.g. `india-china-border-tensions`) and **Data Pages** (e.g. `pm-fasal-bima-claims`) drive the highest internal-link clicks because readers actively scroll to verify primary source documents.
- **Deep Research** explainers (e.g. `upi transaction limit rural`) have the highest engaged session durations (avg 3.5 minutes).

## 2. Key Learnings & Strategy Shift
- Stubs filtration works as designed — stubs remain 404, preventing dilution of site quality.
- Sourcing transparency (evidence score display) significantly boosts second-content click-through rates. Readers trust pages that display clear audit scores.
