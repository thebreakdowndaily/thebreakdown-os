# EDITORIAL OPERATIONS GUIDE (v1.0)

**Target Audience:** Editors, Journalists, Desk Lead, Fact Checkers  
**Release Target:** POP-1.0 Release 3 (P3)

## 1. Editorial Lifecycle Workflow

```
[ 1. Draft Assignment ] 
        │
        ▼
[ 2. Research Complete ] (Evidence Registered in Claim Registry)
        │
        ▼
[ 3. Evidence Verified ] (Primary Sources Attached & Hashed)
        │
        ▼
[ 4. Gold Standard Review ] (7-Phase Multi-Disciplinary Audit)
        │
        ▼
[ 5. Approved for Publish ] ──► [ 6. Published Projection ]
```

## 2. Publishing Checklist
- [ ] Primary sources attached to all claims (Min 100+ sources per volume)
- [ ] No prohibited false-certainty language ("clearly," "obviously," "undoubtedly")
- [ ] 7 Mandatory Narrative Blocks completed in exact constitutional order
- [ ] Both Reader Mode (680px serif reading column) and Research Mode previewed
- [ ] Gold Standard 7-Phase Audit signed off by lead auditor

## 3. Correction & Revision Workflow
- [ ] Corrections must append an immutable version record via `createNewClaimVersion()`
- [ ] Public stories display revision history and timestamped audit log in `TrustLayerPanel`
