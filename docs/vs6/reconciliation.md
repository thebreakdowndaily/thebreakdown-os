## Reconciliation Classification Summary

1. **CANONICAL (3)**: System health evaluation contracts, Newsroom signals/scorecard baseline, Governance policy definitions.
2. **PROJECTION (5)**: Mission Control executive briefing, Operations dashboard projection, Release readiness certification, Editorial scorecard, Outcome tracking.
3. **OPERATIONAL (4)**: Control plane manager & extensions, Worker runner & scheduler, Operational resilience & incident recovery, Observability & distributed tracing.
4. **DERIVED (2)**: Job status summaries, Operational alerts.
5. **PARTIAL (1)**: Incident lifecycle (currently in-memory; fully satisfies existing operational resilience tests without requiring database changes).
6. **MOCK / LEGACY / DUPLICATED (0)**: Zero mock data used in production pathways; legacy debug routes properly return 404.
