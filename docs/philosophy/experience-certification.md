# EXPERIENCE CERTIFICATION STANDARD (NOS-CERT-v1.0)

**Governing Standard:** Level 3 Experience Governance Layer  
**Target:** Enforcement of the Narrative Operating System (NOS) Philosophy  
**Requirement:** Every reader-facing surface must pass Experience Certification before publication or deployment.

## 2. The One Question Rule (Mandatory Layout Constraint)

> **"Every screen answers exactly one primary question."**

*   **The Beginning:** *"Why should I care?"*
*   **Story Surface:** *"What happened?"*
*   **Problem Surface:** *"Why did it happen?"*
*   **Evidence Surface:** *"How do we know?"*
*   **Fix Surface:** *"What can be done?"*
*   **Comparison Surface:** *"Which approach fits which circumstances?"*
*   **Reflection Surface:** *"What have I learned?"*

If a screen attempts to answer multiple primary questions simultaneously, it is non-compliant and must be split.

---

## 3. Experience Review Board (ERB) Evaluation Checklist

To achieve certification, a feature must receive a **YES** on all five constitutional criteria:

| Evaluation Criterion | Test Question | Verification Gate |
| :--- | :--- | :---: |
| **1. Uncertainty Reduction** | Does this surface resolve ambiguity through verifiable evidence? | YES / NO |
| **2. Curiosity Increase** | Does this surface naturally motivate the next question in the journey? | YES / NO |
| **3. Narrative Continuity** | Can the reader immediately identify where they are in the narrative? | YES / NO |
| **4. Cognitive Load Focus** | Does this surface obey the One Question Rule without visual clutter? | YES / NO |
| **5. Anti-Pattern Compliance** | Is this surface 100% free of infinite feeds, outrage bait, or clickbait? | YES / NO |
