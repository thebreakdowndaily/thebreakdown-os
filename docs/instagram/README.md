# The Breakdown Instagram skills

A curated set of ten project-local agent skills for The Breakdown's evidence-led Instagram workflow.

## Included capabilities

- Brand voice card
- Claim-level source research
- Caption writing and checks
- Carousel storyboarding
- Reels scripting
- Seven-day content calendar
- Long-form-to-Instagram repurposing
- Profile audit from supplied material
- Performance audit from supplied Insights
- Editorial quality audit

## Integration

Skills are stored under .agents/skills/ and catalogued in .agents/skills.md. Existing Instagram instructions under .opencode/ are preserved; these skills supplement rather than replace the existing formatter or command.

## Provenance

The skills are original, The Breakdown-specific adaptations informed by review of the MIT-licensed sources named in THIRD_PARTY_NOTICES.md. No upstream executable scripts are included.
