# Welcome Sequence

The 5-email welcome sequence is designed to onboard new subscribers and familiarize them with our methodology.

1. **Welcome + What to expect (immediate)**
   - Welcomes the user.
   - Explains the frequency and types of content they will receive.
2. **Best-of compilation (Day 2)**
   - Links to top performing past articles.
3. **Methodology explainer (Day 5)**
   - Explains how we gather evidence, use primary sources, and verify facts.
4. **Deep dive recommendation (Day 7)**
   - Recommends a long-form deep dive piece based on broader topics.
5. **Feedback request (Day 14)**
   - Asks the user for feedback on the content so far.

*Note: This is documentation only, not automated in our codebase. The sequence requires configuration directly within the newsletter provider (e.g., Beehiiv).*
